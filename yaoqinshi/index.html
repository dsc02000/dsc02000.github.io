妖琴师

角色简介

妖琴师是《阴阳师》手游中的SR级式神，虽然定位为SR，但其核心的“拉条”能力使其在游戏前期和特定阵容中拥有极高的战略价值。他身着古琴，手持琴键，能够通过演奏美妙的旋律来改变场上单位的速度。

核心机制：妖琴师的一技能可以拉条（增加行动条），二技能提供攻击力加成，三技能则是范围性的拉条与增伤。他是斗技中控制流队伍和PVE速刷队伍不可或缺的辅助。

与同为拉条位的大天狗相比，妖琴师不消耗鬼火且带有控制效果，是新手玩家最友好的拉条式神之一。

技能详解

一技能：琴音缭绕 Lv.1 - Lv.5

妖琴师弹奏古琴，使全体队友的行动条增加15%，并造成攻击力100%的伤害。这是妖琴师最基础的功能，用于保证队友的先手机会。

二技能：共鸣之律 Lv.1 - Lv.5

妖琴师弹奏古琴，为所有友方目标增加攻击力20%。该效果可以叠加，是提升队伍输出的关键辅助技能。

三技能：狂想之律动 Lv.1 - Lv.5

妖琴师弹奏古琴，使全体队友行动条增加25%，并造成攻击力100%的伤害。该技能有25%的概率使目标陷入“混乱”状态。这是妖琴师在PVP中具备控制能力的来源。

御魂搭配与阵容

推荐御魂方案

妖琴师作为拉条位，首要属性是速度。为了最大化拉条效率，通常推荐以下两种御魂配置：

方案一：招财猫（PVE/日常推荐）
御魂名称： 招财猫 4件套 + 速度/效果抵抗 2件套
速度属性： 188+ (满速) 或 195+
属性解析： 招财猫每回合有30%概率提供鬼火，确保队伍在长时间战斗中不缺火。速度拉满是关键。
方案二：火灵（PVP/斗技推荐）
御魂名称： 火灵 4件套 + 效果抵抗/生命 2件套
速度属性： 188+ (满速) 或 195+
属性解析： 开局直接提供3点鬼火，让队伍核心输出能直接释放大招，适合快节奏的斗技环境。

热门阵容搭配

1. 控制流队伍： 妖琴师 + 鬼使黑 + 山兔 + 椒图 + 雪女。利用妖琴师拉条，确保雪女先手控制，椒图分摊伤害，鬼使黑收割。

2. 逢魔之时速刷： 妖琴师 + 姑获鸟 + 阎魔 + 辉夜姬/招财猫。妖琴师负责拉条，保证全员行动，快速清理小怪。

常见问题

妖琴师和山兔哪个拉条好？

妖琴师不消耗鬼火且带有控制，山兔消耗鬼火。新手推荐妖琴师，省火且稳定。

三技能的混乱有用吗？

有用。在PVP中，混乱可以让对手攻击队友，是控制流队伍的重要一环。
